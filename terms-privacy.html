Terms & Privacy

Last Updated: August 2026

At Sendly, we believe your data is solely your property. We engineered this suite of tools to transfer files, mirror screens, and process sensitive developer code as quickly and securely as possible—without hoarding your personal information, requiring user logins, or keeping your data longer than mathematically necessary.

Privacy Policy & Architecture

1. Zero-Account Architecture

We do not require you to create an account, log in, or provide an email address or phone number to use Sendly. Because we do not collect personal profiles, device tracking identifiers, or behavioral databases, we have zero personal user data to share, monetize, or disclose to advertisers or third-party brokers.

2. Ephemeral File Storage (Standard Transfers)

For cloud-routed transfers, Sendly acts strictly as an automated temporary bridge between sender and receiver:

  • Instant Deletion: The exact moment a file payload is successfully downloaded by the receiver, its encrypted binary blob is permanently and irreversibly purged from our servers.
  • Time-Out Deletion: If a file is uploaded but unclaimed within 10 minutes, automated cron schedulers scrub it entirely from all memory and disk storage.

3. Zero-Knowledge Encryption

Sendly offers optional Client-Side AES-GCM 256-bit Encryption. When you choose to protect your transfer with a password, your file is mathematically scrambled inside your active web browser memory before a single byte leaves your machine. We have zero knowledge of your plaintext files, never transmit or record decryption passwords, and cannot decrypt your data under any circumstances.

4. Local Network P2P Discovery (Local Drop)

Our ⚡ Local Drop tool enables serverless, peer-to-peer file transfer over localized Wi-Fi and Ethernet networks using raw WebRTC protocols:

  • Direct Peer Coupling: Once matching subnet device signatures are discovered, file transfers beam directly between devices across your local router without ever traversing external cloud servers or public internet storage.
  • No Size or Bandwidth Limits: Because transfers occur exclusively over your local local area network (LAN), your files remain entirely within your hardware boundaries at localized Gigabit speeds.

5. Offline Developer Suite (Diff Checker & JSON Tools)

When utilizing Sendly's developer productivity tools—including 🔍 Diff Checker, ⚡ JSON Formatter, and 📊 JSON Cracker—all string transformations, syntax highlighting, diff logic, and node graph renderings execute 100% locally within your client-side JavaScript engine. Sensitive source code, database schemas, API response payloads, and tokens pasted into these workspaces are never transmitted over network sockets or written to external logs.

6. Standalone Desktop & Progressive Web App (PWA)

Installing Sendly as a native Windows or macOS desktop app operates via modern sandboxed Chromium PWA service worker standards. Our application operates completely within secure OS containers without installing background tracking daemons, system registry hooks, or invasive analytics monitors.
